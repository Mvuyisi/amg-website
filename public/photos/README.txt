PHOTOS FOR THE WEBSITE
======================

Put the website's photos in this folder.

How to add a photo
1. Copy the photo file into this folder, for example hero-portrait.jpg
2. Open src/content/images.js and find the spot the photo is for
   (each spot has a label saying what photo it needs).
3. Set that spot's src to "/photos/hero-portrait.jpg" (the file name you used).
4. Write the alt text: one plain sentence describing what is in the photo.
5. If Apostle's face is cut off, change the spot's focus, for example from "top" to "50% 20%".

Recommended sizes
- Portraits (tall photos): at least 1200 pixels wide.
- Wide photos: at least 1600 pixels wide.
- Save as JPG.
- Keep each file under about 500 KB after compression (for example with squoosh.app).

Tips
- The Home portrait should be sharp and well lit, with some free space beside Apostle,
  because the welcome video and his name sit over the photo.
- Use simple file names: lowercase, no spaces (hero-portrait.jpg, not "IMG 2041.JPG").
- Only use photos the ministry has permission to publish.
